# Blind Helper

## LiDAR-Based Assistive Obstacle Detection Device

Blind Helper is an open-source electronic assistive device designed to help blind and visually impaired people detect obstacles while walking.

The first prototype uses an ESP32-C3 Super Mini microcontroller and a TF-Luna LiDAR distance sensor.

The LiDAR continuously measures the distance to objects in front of the user. The ESP32 processes the measurements and provides tactile feedback using a vibration motor.

As an obstacle becomes closer, the vibration intensity increases.

---

## Project Objective

The objective of this project is to develop a compact, affordable and modular electronic mobility aid capable of providing real-time information about nearby obstacles.

The device is intended to complement conventional mobility aids such as the white cane rather than replace them.

The project will be developed progressively, starting with simple forward obstacle detection and later expanding toward multidirectional sensing, stair and drop-off detection, navigation and intelligent environmental awareness.

---

# Version 1

The first prototype consists of:

- ESP32-C3 Super Mini
- TF-Luna LiDAR
- Vibration motor
- 2N2222 NPN transistor
- Flyback diode
- 470 ohm transistor base resistor
- 10 kohm base pull-down resistor
- Rechargeable power supply

The TF-Luna communicates with the ESP32 using I2C.

### Current Pin Assignment

| Function | ESP32-C3 GPIO |
|---|---:|
| TF-Luna SDA | GPIO4 |
| TF-Luna SCL | GPIO3 |
| Vibration motor PWM | GPIO1 |

# Operating Principle

The system operates according to the following chain:

Obstacle

↓

TF-Luna LiDAR

↓

Distance measurement

↓

ESP32-C3

↓

Distance processing

↓

PWM generation

↓

2N2222 motor driver

↓

Vibration motor

The vibration intensity increases as the measured obstacle distance decreases.

---

# Current Detection Strategy

The first prototype activates the vibration warning when an obstacle is approximately 100 cm or closer.

Example behavior:

| Distance | Feedback |
|---:|---|
| > 100 cm | Motor OFF |
| 70–100 cm | Weak vibration |
| 40–70 cm | Medium vibration |
| 15–40 cm | Strong vibration |
| <= 15 cm | Maximum vibration |

These values are experimental and will be optimized through testing.

---

# Hardware Architecture

The TF-Luna performs optical distance measurements.

The ESP32-C3 reads these measurements through the I2C interface.

GPIO1 generates a PWM signal controlling a 2N2222 transistor.

The transistor controls the vibration motor because the motor should not be powered directly from an ESP32 GPIO.

A flyback diode protects the transistor and controller from inductive voltage transients generated by the motor.

# Development Roadmap

## Version 1

Single forward-facing LiDAR sensor and distance-dependent vibration feedback.

## Version 2

Improved power management, battery monitoring and additional user feedback.

## Version 3

Multiple sensors for directional obstacle detection:

- Left
- Center
- Right

Different vibration patterns can communicate obstacle direction.

## Version 4

Ground and drop-off detection.

A downward-facing distance sensor will detect:

- Stairs
- Pavement edges
- Holes
- Sudden ground-level changes

An IMU may be incorporated to compensate for changes in sensor orientation while walking.

## Version 5

Advanced smart navigation features may include:

- Object recognition
- Camera integration
- GPS
- Smartphone connectivity
- Voice guidance
- Environmental awareness
- AI-based scene interpretation

# Safety Notice

This project is currently an experimental research prototype.

It has not been certified as a medical device, personal protective device or professional mobility aid.

It must not be relied upon as the sole means of navigation.

Blind and visually impaired users should continue using established mobility aids such as a white cane, guide dog and professional orientation and mobility techniques.

Sensor measurements can be affected by environmental conditions, object reflectivity, sensor orientation and electronic or software failures.
